export const data = await reportData('exp006', { allowUnavailable: true });
export const cfg = data?.configuration;
export const s = data?.summary;
export const seconds = cfg ? round(cfg.presentations * cfg.presentation_ms / 1000, 1) : 'unavailable';
export const ids = (network, rule) => cfg ? cfg.digits.map(d => `${network}__digit${d}__${rule}`) : [];
export const span = (network, rule, key, scale = 1, digits = 2) => {
  const v = ids(network, rule).map(id => s?.[id]?.[key]).filter(x => x != null).map(x => x * scale);
  if (!v.length) return 'unavailable';
  const lo = round(Math.min(...v), digits);
  const hi = round(Math.max(...v), digits);
  return lo === hi ? `${lo}` : `${lo} to ${hi}`;
};

## Abstract

{data ? <p>exp001 to exp005 changed the digit every 200 ms, so the input to each synapse kept switching. Here each network saw a single digit for {seconds} s, without a reset. We used the rate-matched exp022 TR02 pair (PING and COBA with a 25 Hz activity ceiling, seed {String(cfg.seed)}) and {cfg.digits.length} random digits ({cfg.digits.join(', ')}), each started from the trained weights. Every digit ran twice: with frozen weights, and with van Rossum STDP plus synaptic scaling on the sensory weights X→E. Across digits, PING's rhythmicity contrast went from {span('ping', 'both', 'rhythm_contrast_first')} in the first second to {span('ping', 'both', 'rhythm_contrast_last')} in the last with plasticity, against {span('ping', 'frozen', 'rhythm_contrast_last')} with frozen weights. Its rhythm frequency ended at {span('ping', 'both', 'rhythm_frequency_hz_last', 1, 0)} Hz with plasticity and {span('ping', 'frozen', 'rhythm_frequency_hz_last', 1, 0)} Hz frozen. Synapses from the digit's own pixels changed on average by {span('ping', 'both', 'digit_net_change_last', 100, 0)}% of the trained mean weight in PING and {span('coba', 'both', 'digit_net_change_last', 100, 0)}% in COBA. In PING, {span('ping', 'both', 'digit_potentiated_last', 100, 0)}% of them were potentiated and {span('ping', 'both', 'digit_depressed_last', 100, 0)}% depressed. Synapses from the other pixels changed by {span('ping', 'both', 'other_net_change_last', 100, 0)}% in PING and {span('coba', 'both', 'other_net_change_last', 100, 0)}% in COBA. One seed and one image per digit; ranges span the digits, without uncertainty estimates.</p> : <p>No completed evidence is selected.</p>}

## Discussion

### Main claim

- With one steady digit, does van Rossum plasticity potentiate or depress the active synapses, and how does that change the PING rhythm?

### Mechanism

- Equation 4: independent firing drives weights towards the trained mean. Does PING's cycle locking add net potentiation (inputs fire before E spikes in each cycle) or depression?
- What does scaling add when STDP changes the rate?

### Objections

- Rate: do PING and COBA fire at the same E rate on these digits? If not, pairing rates differ.
- Three digits, one image each: is the effect the same across digits?

### Limitations

- One seed (42) and one stream order: no uncertainty estimates.
- Synaptic scaling is compressed in time 100x (tau 1 s, not 100 s); STDP is not.
- Only the sensory weights X->E are plastic; E->I, I->E and the readout are fixed.
- One image per digit; 10 s; no accuracy measured.

### Next steps

- More digits or images; longer exposure; STDP only (no scaling); compare with exp002's changing stream.

*/}
