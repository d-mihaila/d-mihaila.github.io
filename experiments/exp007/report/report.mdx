import { reportData, round } from '../../../site/src/lib/report-data';
export const data = await reportData('exp007', { allowUnavailable: true });
export const cfg = data?.configuration;
export const s = data?.summary;
export const seconds = cfg ? round(cfg.presentations * cfg.presentation_ms / 1000, 1) : 'unavailable';
export const ids = (network, rule) => cfg ? cfg.digits.map(d => `${network}__digit${d}__${rule}`) : [];
export const range = values => {
  const v = values.filter(x => x != null && Number.isFinite(x));
  if (!v.length) return 'unavailable';
  const lo = Math.min(...v);
  const hi = Math.max(...v);
  return [lo, hi];
};
export const show = (values, scale = 1, digits = 2) => {
  const r = range(values.map(x => x == null ? null : x * scale));
  if (r === 'unavailable') return r;
  const lo = round(r[0], digits);
  const hi = round(r[1], digits);
  return lo === hi ? `${lo}` : `${lo} to ${hi}`;
};
export const span = (network, rule, key, scale = 1, digits = 2) => show(ids(network, rule).map(id => s?.[id]?.[key]), scale, digits);
export const effect = (network, key, scale = 1, digits = 2) => cfg ? show(cfg.digits.map(d => data?.scaling_effect?.[`${network}__digit${d}`]?.[key]), scale, digits) : 'unavailable';

## Abstract

{data ? <p>exp006 applied STDP and synaptic scaling together. Here we separate them. The rate-matched exp022 TR02 pair (PING and COBA with a 25 Hz activity ceiling, seed {String(cfg.seed)}) saw one digit for {seconds} s, for digits {cfg.digits.join(', ')}, with exp006's images and spike trains. Each digit ran three times from the trained weights: frozen, with van Rossum STDP only, and with STDP plus scaling on the sensory weights X→E. In PING, the E rate in the last second was {span('ping', 'frozen', 'rate_hz_last', 1, 1)} Hz frozen, {span('ping', 'stdp', 'rate_hz_last', 1, 1)} Hz with STDP only and {span('ping', 'both', 'rate_hz_last', 1, 1)} Hz with scaling added; the scaling setpoint was the frozen rate. Its rhythmicity contrast ended at {span('ping', 'frozen', 'rhythm_contrast_last')}, {span('ping', 'stdp', 'rhythm_contrast_last')} and {span('ping', 'both', 'rhythm_contrast_last')}. Synapses from the digit's own pixels changed by {span('ping', 'stdp', 'digit_net_change_last', 100, 0)}% of the trained mean weight with STDP only and {span('ping', 'both', 'digit_net_change_last', 100, 0)}% with scaling. Synapses from the other pixels, whose inputs hardly fire, changed by {span('ping', 'stdp', 'other_net_change_last', 100, 0)}% and {span('ping', 'both', 'other_net_change_last', 100, 0)}%. Adding scaling changed each E cell's total input by a median factor of {effect('ping', 'afferent_ratio_median')} in PING and {effect('coba', 'afferent_ratio_median')} in COBA. One seed and one image per digit; ranges span the digits, without uncertainty estimates.</p> : <p>No completed evidence is selected.</p>}

## Discussion

### Main claim

- What does STDP alone do to a trained PING network shown one digit, and what does scaling add or undo?

### Mechanism

- STDP: eq. 4 drift towards the trained mean on active inputs, plus PING's cycle-locked timing.
- Scaling: one factor per E cell that pulls each cell's rate to the setpoint; it moves silent inputs too.

### Objections

- Adding scaling also changes spike times, so the paired difference is not scaling in isolation.
- Does the STDP + scaling run reproduce exp006? Check before comparing.

### Limitations

- One seed (42) and one stream order: no uncertainty estimates.
- Synaptic scaling is compressed in time 100x (tau 1 s, not 100 s); STDP is not.
- Only the sensory weights X->E are plastic; E->I, I->E and the readout are fixed.
- One image per digit; 10 s; no test accuracy.

### Next steps

- Scaling only; longer exposure; more digits or images; plastic E->I and I->E.

*/}
