## Abstract

We ask whether a fixed contrast cue can select which of two MNIST images is
reconstructed by a spiking readout. The shared input encoder and pixel readout
are trainable; the intervening attention connections remain fixed. This report
is a scaffold: no completed training result for the spiking pixel readout is
available, and reconstruction performance has not been established.

## Methods

1. **Spike-count reconstruction loss.** Count each pixel neuron's spikes within
   the attended scoring window and minimise pixel mean-squared error:

   $$
   \mathcal{L} = \frac{1}{784B}
   \sum_{b=1}^{B}\sum_{p=1}^{784}
   \left(\frac{n_{bp}}{n_{\mathrm{white}}} - x_{bp}\right)^2.
   $$

   Here, $\mathcal{L}$ is the loss, $B$ is batch size, $b$ indexes images,
   $p$ indexes the 784 pixels, $n_{bp}$ is the corresponding output spike count,
   $n_{\mathrm{white}}$ is the configured count representing white, and $x_{bp}$
   is the original attended image's pixel value divided by 255. Counts remain
   unclipped so overshoot is penalised. Surrogate gradients train the shared
   input encoder and pixel readout; attention weights stay fixed. No
   classification or firing-rate penalty is added.
