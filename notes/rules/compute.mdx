# Compute Rules

Adapted from Eoin Murray's upstream Compute Rules.

1. Simulations require the authorization described in
   [Experiment Rules](/notes/rules/experiment#execution-permission). Paid work
   requires authorization for its scope and resources; do not ask again within
   existing authorization. Inspect the recipe and resource request before launch.
2. Use the local Mac for development, small tests, plotting and analysis. It has no
   CUDA; do not run large training jobs on it.
3. Only hosts listed in [Compute Access](/notes/rules/compute-access) may be used.
   Upstream's hosts and accounts (Hetzner, Olorin, CSD3/Wilkes3 `OLEARY-*`) belong
   to Eoin Murray's group; use them only with his explicit agreement.
4. `libraries/hpc` is configured for Cambridge CSD3 accounts, and
   `libraries/modal_dispatcher` needs your own Modal account. Configure either before
   use. Keep run/job/call IDs and logs. Investigate ambiguous submissions before
   retrying; collect and validate outputs before cleanup. Keep credentials out of Git
   and chat.

Read [Compute Access](/notes/rules/compute-access) only for the host being operated.
